# 2026Q4 VLA Manipulation Robot Software Stack Curriculum

# 0. 목표

이 커리큘럼의 최종 목표는 **Vision-Language-Action(VLA) 기반 manipulation robot software stack을 구현하는 것**이다.

목표:

- 로봇팔 kinematics / dynamics / control 이해
- Vision-Language-Action 구조 이해
- imitation learning 기반 manipulation policy 구현
- vision과 robot state를 결합한 action model 개발
- simulation 기반 pick-and-place system 구현
- 물류 picker와 같은 general manipulation robot으로 확장 가능한 기반 확보

전체 pipeline:

```text
Vision + Language
        ↓
Multimodal Representation
        ↓
Action Model / Policy
        ↓
Motion Planning + IK
        ↓
Controller
        ↓
Robot Manipulation
```
