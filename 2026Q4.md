> **최종 목표**
>

## Reinforcement Learning — Learning to Act

### 목표
물리적인 제어 문제를 sequential decision-making problem으로 바꾸고 policy를 학습시킨다.

### 핵심

- Bellman equation
- MC / TD
- policy gradient

### 핵심 능력

```text

success/failure → termination
```

# 6. Vision / VLM의 위치

Vision과 VLM은 처음부터 붙이지 않는다.

```text
Stage 1
GT robot/object state
→ action model

Stage 2
camera
→ explicit object / gripper state
→ action model

Stage 3
camera
→ vision latent
→ action model

Stage 4
vision + language + proprioception
→ task representation
→ action model
```

역할 분리:

```text
VLM
→ 무엇을 해야 하는가?
→ 어떤 물체가 목표인가?

Vision / Tracker
→ 지금 물체와 gripper가 어디 있는가?

Action Model
→ 어떻게 움직일 것인가?

Controller
→ 실제로 실행
```

이번 학기에는 pretrained VLM을 직접 학습하는 것을 필수 목표로 두지 않는다.

3. 처음부터 vision/VLM을 붙이지 않는다.
4. GT state는 초기 curriculum stage로 사용한다.
5. RL만 고집하지 않고 문제에 맞게 BC/action model을 사용한다.
6. perception / action model / controller / systems failure를 분리해서 분석한다.
7. 최종 기본 구조는 **vision + proprioception**이다.
8. 목표는 특정 물체를 잘 집는 것이 아니라 **새로운 상황에 대응 가능한 manipulation software**다.

# 10. 학기 종료 기준

16주 후 다음을 스스로 설명하고 구현할 수 있으면 완료로 본다.

> 로봇의 pose, joint state, velocity, Jacobian과 dynamics의 기본 의미를 이해한다.  
> feedback controller를 설계하고 disturbance에 대한 성능을 정량 평가할 수 있다.  
> 동일한 문제를 MDP로 정의하여 PPO policy를 학습하고 baseline과 비교할 수 있다.  
> manipulator의 robot/object/goal state로 trajectory dataset을 구성하고 action model을 학습해 closed-loop pick-and-place를 수행할 수 있다.  
> C++/OS 관점에서 perception, inference, control을 서로 다른 주기로 실행하는 로봇 소프트웨어 구조를 설명할 수 있다.  
> 이후 vision/VLM을 기존 action pipeline의 어느 위치에 연결할지 설계할 수 있다.
