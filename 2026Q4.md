# 2026Q4 VLA Manipulation Robot Software Stack Curriculum

# 0. 목표

이 커리큘럼의 최종 목표는 **Vision-Language-Action(VLA) 기반
manipulation robot software stack을 구현하는 것**이다.

목표:

-   로봇팔의 kinematics / dynamics / control 이해
-   Vision-Language-Action 구조 이해
-   imitation learning 기반 manipulation policy 구현
-   vision과 robot state를 결합한 action model 개발
-   simulation 기반 pick-and-place system 구현
-   장기적으로 물류 picker와 같은 general manipulation robot으로 확장
    가능한 기반 확보

전체 구조:

``` text
Vision + Language
        ↓
Multimodal Representation
        ↓
Action Model / Policy
        ↓
Motion Planning + IK
        ↓
Controller
        ↓
Robot Manipulation
```

휴머노이드 locomotion이나 단순 motion generation보다 **보고 → 이해 →
행동 생성 → 제어 → 조작**의 전체 pipeline 구현을 우선한다.
