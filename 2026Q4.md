# 4. 진행 규칙

1. **프로젝트를 선수과목 때문에 멈추지 않는다.** 필요한 개념만 먼저 학습하고 다시 프로젝트로 돌아온다.
2. **Baseline이 먼저다.** `nominal → deterministic disturbance → randomization` 순서를 지킨다.
3. **RSL-RL은 baseline이다.** 최종 목표는 custom PyTorch PPO와 policy architecture를 직접 수정하는 것이다.
4. **Vision은 이번 학기에서 하지 않는다.** state/proprioception 기반 control을 먼저 완성한다.
5. **튜토리얼 완료보다 재구현 능력이 중요하다.** 문서를 닫고도 다시 만들 수 있어야 한다.
6. **RL이 반드시 PD보다 좋아야 하는 것은 아니다.** 비교와 분석 자체가 결과다.
