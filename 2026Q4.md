# 10-Week Self-Directed Semester

> **Modern C++ (3) + Operating Systems (3) + Machine Learning (3) + Robot Learning + Isaac Lab Robotics Project (6) + LLM Inference Optimization Capstone (6)**
>
> 핵심: **C++/OS는 llama2.c inference optimization에, ML/Robot Learning은 Isaac Lab 기반 action model 프로젝트에 직접 연결한다.**
>
> 목표:
> - C++/OS 수준에서 AI 시스템의 동작과 성능 병목을 분석한다.
> - Neural Network부터 Transformer/LLM까지 모델 구조를 구현 수준에서 이해한다.
> - Isaac Lab에서 robot learning pipeline을 구축하고 action model을 평가한다.
