## C++ / OS / ML / RL / Isaac Sim + Isaac Lab / SO-101 Manipulation

> 목표: 16주 동안 **Modern C++(3학점) + Operating Systems(3학점) + Machine Learning/PyTorch(3학점) + Reinforcement Learning(3학점) + Robotics Project(6학점)**을 하나의 연결된 커리큘럼으로 진행한다.

Vision은 사용하지 않는다.

환경 또는 외부 시스템이 다음 공간 정보를 **이미 알고 있다고 가정**한다.

goal position / orientation

# 6. 진행 원칙

1. **프레임워크 API 암기보다 원리를 우선한다.** Boilerplate는 AI assistant를 적극 활용한다.
2. **핵심 algorithm/data flow는 직접 이해한다.** loss, tensor shape, state/action/reward는 설명하고 수정할 수 있어야 한다.
3. **Baseline을 먼저 만든다.** Gimbal은 PD → PPO, SO-101은 scripted/BC → ACT 순서로 간다.
4. **Vision은 이번 학기에서 제외한다.** object/goal pose는 known state로 제공한다.
5. **Gimbal RL은 8주차까지 끝낸다.** 이후 Isaac Lab 자체를 계속 파는 것보다 manipulator policy로 넘어간다.
6. **SO-101 후반부는 VLA를 직접 학습하는 프로젝트가 아니다.** state-based manipulation을 먼저 성공시키고 language conditioning은 선택적으로 추가한다.
7. **DirectRLEnv를 먼저 사용한다.** Manager-based workflow는 필요할 때만 본다.
8. **Randomization은 하나씩 추가한다.** 실패 원인을 분리할 수 있어야 한다.
9. **실험은 재현 가능하게 기록한다.** seed, config, dataset version, checkpoint, metric을 남긴다.
10. **최종 목표는 코드를 많이 타이핑하는 것이 아니라, 모델을 이해하고 수정하고 실험하는 능력이다.**
