For robotics/simulator code, prioritize:
- references, pointers, const, value categories
- scope and object lifetime
- structs/classes and constructors
- RAII and ownership

# 3. Machine Learning & Mathematical Foundations — 3 credits

## Main reference

**Kevin P. Murphy, _Probabilistic Machine Learning: An Introduction_ (2022)**

This is the **only required ML textbook** for the semester.

The book is broad enough to cover the mathematical foundations, probabilistic viewpoint, classical ML, neural networks, vision, attention, and Transformers needed for this track. The author explicitly says the book was made more self-contained by adding background material such as linear algebra and optimization; sections marked with `*` are advanced material that can be skipped in an introductory course.

PyTorch documentation is used only as an API reference during implementation weeks.

## Why the reading order is rearranged

The book is written as a reference/textbook, not as a 16-week course tailored to this semester.

For this track, the order is intentionally rearranged around the diagnostic:

1. repair linear algebra / matrix-calculus gaps;
2. build probability properly;
3. spend real time on statistics, especially MLE/MAP/Bayesian/frequentist ideas;
4. add decision theory and information theory;
5. study optimization;
6. connect these foundations to PCA and familiar regression models;
7. move to MLPs, CNNs, attention, and Transformers.

The goal is **not** to finish the entire book.

## Reading rule

Use three levels:

- **CORE** — read carefully and do at least some exercises/code.
- **SELECTED** — understand the idea and key equations; skip long derivations if time is tight.
- **OPTIONAL** — only if ahead or specifically useful for robotics.

This is especially important because some `*` sections are valuable to you even though Murphy marks them as advanced.

## What to read inside the difficult chapters

### Chapter 4 — do not skip this chapter

This is one of the most important chapters for the current gaps.

**Must understand:**

- 4.2 Maximum likelihood estimation
- 4.3 Empirical risk minimization
- 4.5 Regularization
- validation / cross-validation / early stopping
- MAP as regularized estimation
- the conceptual difference between Bayesian and frequentist inference
- credible interval vs confidence interval
- bias-variance tradeoff

**Do not get stuck proving every conjugate-prior result.**

For 4.6, focus on the ideas behind posterior inference and work through one simple conjugate example such as beta-binomial. The later algebra-heavy examples are secondary.

For 4.7, focus on sampling distributions, confidence intervals, and bias-variance. Bootstrap details are useful but optional on the first pass.

### Chapter 5 — selected, not discarded

Chapter 5 is useful because it answers a different question from Chapter 4:

- Chapter 4: **how do we estimate a model?**
- Chapter 5: **given probabilistic predictions, how should we make decisions?**

Read **5.1** carefully enough to understand loss/risk, classification decisions, ROC, precision-recall, regression decisions, and probabilistic prediction.

The deeper hypothesis-testing/model-selection material in 5.2–5.5 can wait.

### Chapter 7 — study the parts that support ML

Prioritize:

- vector spaces / norms
- matrix multiplication
- EVD
- symmetric matrices
- SVD
- pseudoinverse
- least squares
- gradients / Jacobian / Hessian

Do not spend significant time on Schur complements, Kronecker products, LU/QR/Cholesky, etc. unless they become useful later.

### Chapter 8 — do not try to become an optimization specialist

Prioritize:

- convex vs nonconvex
- first-order methods
- learning rate
- momentum
- SGD
- Newton's method conceptually

KKT, proximal methods, derivative-free optimization, and detailed EM optimization are not required for this semester.


Be able to explain:

- kernels
- channels
- receptive fields
- pooling

## Isaac Lab concepts to know by Week 11

### Environment structure

`EnvCfg` is configuration/design.

`Env` is runtime behavior.

For a Direct environment, understand the purpose of:

```text
_setup_scene()
_pre_physics_step(actions)
_apply_action()
_get_observations()
_get_rewards()
_get_dones()
_reset_idx(env_ids)
```

### Simulation timing

Understand:

- physics `dt`
- `decimation`
- policy/control frequency
- render frequency

### Batched simulation

Understand that:

```text
robot.data.*
```

contains tensors for many environments at once.

The policy receives a batch of observations and emits a batch of actions.

### Actions

For the gimbal, deliberately choose one control interface:

- torque target, or
- velocity target, or
- position target

Do not switch interfaces casually while debugging the task.

### Observations

Start small:

- orientation error
- angular velocity
- joint position/velocity if needed
- previous action if useful

Only add more observations when there is a reason.

### Reward

Start interpretable:

```text
- orientation error
- angular velocity penalty
- action magnitude / action-change penalty
```

Then add complexity only after the baseline trains.
