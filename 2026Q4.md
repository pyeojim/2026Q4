# 16-Week Self-Directed Semester
## Intelligent Robot Software / Embodied Manipulation

> **최종 목표**
>
> 시각·언어·로봇 상태를 바탕으로 상황을 이해하고, 적절한 manipulation action을 생성하며,
> 이를 실제 로봇 시스템에서 안정적으로 실행할 수 있는 소프트웨어를 설계한다.

> 핵심은 **“잘 집는 기계” 자체보다 “무엇을 어떻게 집어야 하는지 판단하고 실행하는 로봇 소프트웨어”**다.
> Isaac Sim / Isaac Lab은 학습 목표가 아니라 **가상 실험실**로 사용한다.

# 6. Vision / VLM의 위치

Vision과 VLM은 처음부터 붙이지 않는다.

```text
Stage 1
GT robot/object state
→ action model

Stage 2
camera
→ explicit object / gripper state
→ action model

Stage 3
camera
→ vision latent
→ action model

Stage 4
vision + language + proprioception
→ task representation
→ action model
```

역할 분리:

```text
VLM
→ 무엇을 해야 하는가?
→ 어떤 물체가 목표인가?

Vision / Tracker
→ 지금 물체와 gripper가 어디 있는가?

Action Model
→ 어떻게 움직일 것인가?

Controller
→ 실제로 실행
```

이번 학기에는 pretrained VLM을 직접 학습하는 것을 필수 목표로 두지 않는다.
